South American Land Borders

Chord width is proportional to the length of the shared land border (km) between two countries.

Source: Mondial borders table — source = country1, target = country2, weight = length. Filtered to country pairs where both nations lie in South America. Borders are undirected, so each chord represents one shared frontier. Node order around the circle is computed to place strongly connected countries adjacent and reduce chord crossings.
